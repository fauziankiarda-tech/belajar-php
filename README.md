# Belajar PHP

Project sederhana untuk belajar dasar PHP,
HTML, dan CSS.

## Fitur
- Menampilkan nama siswa
- Menampilkan kelas
- Menggunakan CSS untuk mempercantik tampilan

## Bahasa Pemrograman
- PHP
- HTML
- CSS

## Cara Menjalankan
1. Install XAMPP.
2. Masukkan folder ke htdocs.
3. Jalankan Apache.
4. Buka http://localhost/belajar-php/
